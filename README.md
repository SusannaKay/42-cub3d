# CUB3D
cub3d is a project that aims to master rigor, use of c, paring and raycasting as well as events management

---
## How to use it

```
Git clone && cd <42-CUB3D folder>
Make
``` 
then you just simply need to type on your terminal 

```
./cub3d maps/<map_name.cub>
```
use
WASD to move
left/right arrows to look around

enjoy!
